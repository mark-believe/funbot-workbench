# 共建工作台界面与交互规范

适用于总览、执行、令牌、账号与合约四个工作区。维护日期为 2026-11-24。品牌依据为 Mark 知识库 2026-09-14 确认的《MARK-AI 产品设计与体验标准》。

| 操作者的任务 | 默认看到 | 按需展开 |
|---|---|---|
| 核对一天的变化 | 日期、全队净变化、日初和期末可用、各组时段 | 该时段每个账户的打前、打后、净变化；自选区块和核算公式 |
| 找出需要处理的账号 | 搜索、分组、状态筛选、匹配数量 | 完整地址、持有令牌、可领取金额 |
| 批量执行 | 环境、选择范围、次数、就绪状态 | 单个账号状态、失败原因、回执 |
| 归集令牌 | 读取子账号持仓的入口 | 来源、目标主号、完整编号、数量、费用上限和确认 |

## 工作区规则

- 顶部保留四个稳定工作区，以及真实环境和测试数据选择器。解锁入口与当前密钥状态放在同一区域。
- 总览默认打开资产对账。战绩与扩组、账户明细、福泽记录各有直接入口。跨区快捷操作应同时选中目标报表。
- 每个打局时段用「查看账户」打开明细弹窗。弹窗带组别、时间、净变化和账户表。关闭后回到原表。日志、令牌归集清单同样按需打开。只读钱包地址默认显示首尾，悬停查看或复制全址；交易最终确认保留完整目标地址。
- 金额注明单位，按列右对齐，使用等宽数字。正值带加号、负值带减号、零显示为 0。读取失败与余额为零分别呈现。
- 操作按钮写明动作和对象。涉及真实交易时，先列出作用范围、目标与费用，再由用户确认。测试模式始终在浏览器内提供模拟响应。
- 延用品牌深夜蓝、行动青和雾白。行动青用于选中态和主要入口；资产增减另用正负号与语义色。使用 8、12、16、24 像素间距表达从属关系。
- 数据表在窄屏内局部横向滚动。长清单限制高度。按钮和展开控件提供可见键盘焦点；动效遵循系统的减少动态效果设置。

## 改版验收

使用现有三组模拟账户。桌面和手机宽度分别检查：进入资产对账、打开第二组明细、核对负值、关闭弹窗并继续查第三组；从战绩指标筛到账户；从令牌中心跳到福泽；切换真实与测试环境。键盘完成同一路径，检查焦点位置。交易确认与失败状态单独验证。
